# KemetForge

Plataforma web para pequenos comércios acompanharem estoque, receitas, vendas, perdas, calendário e gráficos em um único lugar.

## Páginas públicas

- Início
- Sobre nós
- Planos mensal e anual
- Contato
- Login
- Criação de conta

## Sistema interno

- Painel inicial
- Estoque com controle de quantidade
- Receitas
- Vendas
- Perdas e desperdícios
- Calendário anual
- Gráficos de desempenho

O projeto foi desenvolvido com HTML, CSS e JavaScript puros e funciona de forma responsiva em computadores, tablets e celulares.
