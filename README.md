# KemetForge

Plataforma web para pequenos comércios acompanharem estoque, receitas, vendas, perdas, calendário e gráficos em um único lugar.

## Páginas públicas

- Início
- Sobre nós
- Planos mensal e anual
- Contato
- Login
- Criação de conta

## Sistema interno

- Painel inicial
- Produtos e ingredientes
- Estoque com controle de quantidade
- Receitas
- Produção
- Vendas
- Perdas e desperdícios
- Financeiro
- Calendário anual
- IA especialista demonstrativa
- Gráficos de desempenho

O painel permite alternar entre os temas escuro e claro. As telas representam um protótipo visual: os dados, formulários, alertas e respostas inteligentes são demonstrativos e ainda não utilizam banco de dados ou serviços externos.

O projeto foi desenvolvido com HTML, CSS e JavaScript puros e funciona de forma responsiva em computadores, tablets e celulares.
